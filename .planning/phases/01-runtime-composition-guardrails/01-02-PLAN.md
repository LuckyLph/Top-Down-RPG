<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Authored Input Actions asset → player-local adapter | Authored action names/types and asset assignment control the player's required local input surface. |
| Input System callbacks → gameplay behavior | Device events cross into movement and attack routing and must not bypass the configured contract. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-04 | Tampering | `PlayerInputAdapter.TryInitialize` | high | mitigate | Validate the serialized InputActionAsset and exact Player/Move/Attack names before enabling callbacks; return failure for any absence. |
| T-01-05 | Elevation of privilege | Player input routing | medium | mitigate | Route gameplay only through resolved Input System callbacks; remove runtime editor lookup and code-created binding paths that could change player-build behavior. |
| T-01-06 | Repudiation | Input contract startup failure | low | accept | The root reports contextual local startup failures to Unity logs; the offline slice has no identity or audit requirement. |
| T-01-SC | Tampering | Package installs | high | accept | No npm, pip, or cargo package installation occurs in this plan. |
</threat_model>
