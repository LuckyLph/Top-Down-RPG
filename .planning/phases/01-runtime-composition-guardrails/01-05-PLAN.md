<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Physical keyboard/mouse → Input System → player adapter | Real-device input crosses into gameplay behavior and smoke evidence. |
| Runtime sentinel → PowerShell wrapper | A local player log record crosses from the built player into verification outcome aggregation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-15 | Spoofing | Smoke pass evidence | high | mitigate | Require both adapter-routed events and observable movement before the sentinel emits success; PlayMode tests drive actual Input System devices. |
| T-01-16 | Tampering | Player smoke log | medium | mitigate | The wrapper starts the locally built executable with a fixed project-owned `-logFile` path and treats missing/timeout evidence as failure. |
| T-01-17 | Repudiation | All-channel result | medium | mitigate | Store edit/play XML, build result, player log, and smoke outcome under explicit ignored paths and summarize each in console output. |
| T-01-18 | Denial of service | Interactive smoke wait | low | accept | A bounded timeout ends the local wait and returns a failed outcome; there is no network-facing service. |
| T-01-SC | Tampering | Package installs | high | accept | No npm, pip, or cargo package installation occurs in this plan. |
</threat_model>
