| Scene composition root → HUD/camera | Validated player state/transform crosses into presentation components. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-11 | Spoofing | HUD/camera target selection | high | mitigate | Root injects validated player collaborators; HUD/camera do not select arbitrary tagged/global objects. |
| T-01-12 | Tampering | HUD local topology | medium | mitigate | `PlayerHudView.TryResolve` validates the owned hierarchy before the root activates the core. |
| T-01-13 | Denial of service | Scene startup | medium | mitigate | PlayMode tests load the build-configured scene and assert required-core activation plus optional-context absence. |
| T-01-14 | Information disclosure | Diagnostics | low | accept | Failure remains local Unity logging only; no diagnostics UI, telemetry, or network service is introduced. |
| T-01-SC | Tampering | Package installs | high | accept | No npm, pip, or cargo package installation occurs in this plan. |
