<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Authored scene hierarchy → composition root | Required role topology crosses into runtime startup and must be unique/valid. |
| Composition root → domain components | The root supplies cross-context references to player input, navigation, HUD, camera, and later optional domains. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-07 | Tampering | Required scene-role topology | high | mitigate | Validate exact-one required roles and fail before activation; tests cover zero and duplicate cases. |
| T-01-08 | Spoofing | Cross-context collaborator selection | high | mitigate | Restrict discovery to the root-owned hierarchy and use explicit injection, eliminating broad global selection for required core dependencies. |
| T-01-09 | Denial of service | Navigation startup | medium | mitigate | `TryBuild` returns a clear result and keeps the core inactive when owned terrain sources cannot build. |
| T-01-10 | Information disclosure | Startup diagnostics | low | accept | Errors remain local Unity console/log output in an offline developer-only slice (D-02). |
| T-01-SC | Tampering | Package installs | high | accept | No npm, pip, or cargo package installation occurs in this plan. |
</threat_model>
